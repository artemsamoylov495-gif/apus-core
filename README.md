# 🚀 APUS (Advanced Peer-to-Peer Universal System)

> **Высокопроизводительное, децентрализованное P2P-ядро и платформа обмена данными с поддержкой E2E-шифрования, Zero-Copy передачей и умной адаптацией под железо.**
> 
> *Разрабатывается как базовый сетевой транспорт для AerOS, а также как независимое B2B / Mesh решение.*

---

## 🌟 О проекте

**APUS** — это написанная на Rust ультимативная P2P-платформа, совмещающая в себе свойства низкоуровневого сетевого демона, корпоративного файлообменника и децентрализованной приватной Mesh-сети.

Проект полностью создаётся **одним разработчиком** и находится на стадии бета-тестирования. Приветствуется любая обоснованная критика, багрепорты и предложения через Issues!

---

## ⚡ Ключевые особенности (Key Features)

### 🚀 Производительность и транспорт
* **Zero-Copy передача через Linux Kernel:** Использование системных вызовов `splice` / `sendfile` позволяет прокачивать гигабайты данных напрямую из сокета в сокет без лишнего выделения RAM и с минимальной нагрузкой на ЦП.
* **Сверхнизкая задержка (Latency):** Мгновенная валидация, проверка триггеров и сборка манифестов за **~1-2 мс** (`--release`). Реальный сетевой задержка HTTP/Axum веб-стека — порядка **4-5 мс**.
* **Динамическое сжатие (Zstd):** Адаптивное сжатие чанков на лету в зависимости от загрузки CPU и пропускной способности канала.
* **Передача файлов без ограничений (Unlimited):** Поддержка передачи файлов размером 32+ ГБ в потоковом режиме (Streaming Mode) с автоматическим предупреждением при переходе за порог 256 МБ.

### 🌐 Сетевая связность (NAT Traversal & Discovery)
* **Нативная пробивка NAT:** Поддержка **STUN / TURN / ICE / UPnP / PCP / NAT-PMP**. Узлы находят друг друга за CGNAT и фаерволами без сторонних VPN.
* **P2P Local Discovery (mDNS / SSDP):** Автоматический поиск соседей в локальной сети (LAN / Wi-Fi) со скоростью передачи до 10 Гбит/с.
* **RTT / Ping-Aware Routing:** Динамический выбор наиближайших узлов с минимальным пингом.
* **Network Binding (0.0.0.0):** Полноценный доступ к веб-интерфейсу и сервисам с любого устройства в локалке или Mesh-сети.
* **HTTPS Fallback:** Бесшовное переключение на CDN в случае блокировки P2P-трафика провайдером.

### 🛡 Безопасность и «Контекстная вежливость»
* **E2E-Шифрование:** Прозрачное сквозное шифрование файловых потоков и текстовых сообщений.
* **Анти-Спуфинг Никнеймов:** Интеллектуальная защита от подмены личностей через гомоглифы (смешение кириллицы/латиницы).
* **Контекстные триггеры загрузки (triggers.rs):**
  * **AFK (10+ мин):** Лимит раздачи 50%.
  * **Просмотр видео / фильмов:** Лимит раздачи 30%.
  * **Игры / Активная работа:** Мгновенный сброс раздачи в **0%** без микрофризов для пользователя.
* **Жесткий аудит железа (hardware.rs):** Отсечение устаревших HDD. Раздача разрешается только на подходящих узлах (≥8 ГБ ОЗУ, ≥6 потоков ЦП, строго SSD).
* **Целостность данных:** Почаночная валидация SHA-256 прямо во время загрузки.

## 🔀 Три режима работы (Execution Modes)

| Режим | Флаг | Описание | Основные возможности |
| :--- | :--- | :--- | :--- |
| **APUS Core** | *(без флага)* | Низкоуровневый системный демон для разработчиков / AerOS | Минимальный оверхед, C-ABI (.so / .dll) интеграция, CLI |
| **APUS Corp** | `--corp` | B2B-решение для локальных и корпоративных сетей (НИИ, КДЦ) | Web-UI (`:9090`), быстрый поиск МРТ/КТ снимков, LAN-discovery |
| **APUS Mesh** | `--mesh` | Децентрализованная P2P-сеть для пользователей | Вход по кодам/ссылкам (`APUS-XXXX`), P2P-чат, Drag-and-Drop |

## История версий (Release History)

### v0.1 "Shunpo" (Мгновенный шаг)
* Базовое P2P-ядро на Tokio (TCP).
* Модуль аудита железа (`hardware.rs`) и адаптивные триггеры ресурсов (`triggers.rs`).
* Нарезка файлов на 4 МБ чанки, сборка JSON-манифестов и SHA-256 валидация.
* Компиляция в бинарник и C-ABI библиотеки (`.so` / `.dll`).

### v0.5 "Sonido" (Звуковой резонанс)
* Внедрение NAT Traversal (STUN/TURN/ICE/UPnP) и mDNS LAN Discovery.
* Переход на **Zero-Copy** передачу через `splice`/`sendfile`.
* Умная маршрутизация на основе RTT/Ping.
* Разделение проекта на 3 профиля (`Core`, `Corp`, `Mesh`).

### v0.75 "Hirenkyaku" (Витражный шаг) — Current Beta
* **Архитектурный рефакторинг:** Выделение `corp.rs`, вшитый нативный UI (`index.html` через `include_str!`).
* **Полноценный Mesh & P2P-комнаты:** Генерация инвайт-кодов (например, `APUS-8839-X`), подключение в 1 клик.
* **E2E-Шифрование:** Защищенный приватный P2P-чат и передача файлов.
* **Анти-Спуфинг & UX:** Защита от подмены ников, генерация палитра-аватаров по хэшу, интерактивная Drop-zone и живой поиск.
* **Сетевой биндинг `0.0.0.0`:** Доступ к дашборду с мобильных устройств и планшетов.

## ⚒️ Быстрый запуск (Quick Start)

### Требования
* **Rust** (MSRV 1.75+)
* **Cargo**

```bash
# Клонирование репозитория
git clone [https://github.com/KunagoRu/APUS.git](https://github.com/KunagoRu/APUS.git)
cd APUS

# 1. Запуск базового демона (APUS Core)
cargo run --release --bin apus-core

# 2. Запуск B2B-панели (APUS Corp)
cargo run --release --bin apus-corp
# Веб-панель доступна по адресу: http://localhost:9090 либо же http://0.0.0.0:9090 (или по IP устройства в сети)

# 3. Запуск децентрализованной Mesh-сети (APUS Mesh)
cargo run --release --bin --apus-mesh
